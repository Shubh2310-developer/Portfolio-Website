# Shubh's Portfolio Website

A modern, responsive portfolio website built with Next.js, TypeScript, and Tailwind CSS.

## Features

- 🎨 Modern and clean design
- 📱 Fully responsive
- ⚡ Fast performance
- 🌙 Dark mode support
- 🎭 Smooth animations
- 📝 Blog section
- 📊 Projects showcase
- 📬 Contact form
- 🔍 SEO optimized

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion
- Shadcn UI
- React Icons
- EmailJS

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/shubh-portfolio.git
cd shubh-portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Customization

1. Update personal information in `src/lib/constants.ts`
2. Modify the theme in `src/styles/globals.css`
3. Add your projects in `src/data/projects.ts`
4. Add your blog posts in `src/data/blog.ts`

## Deployment

The site is deployed on Vercel. You can deploy your own version by:

1. Fork this repository
2. Create a new project on Vercel
3. Import your forked repository
4. Deploy!
